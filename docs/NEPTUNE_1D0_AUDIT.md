## Follow-up: bridge identity and draw consumers

Animated colors force dynamic submission but do not themselves mutate snapshot topology. 253–305 publishes shared handles; retained scene keeps prior submissions. 307–329 bundle load increments a separate bundle generation, clears inventory entries for bundle, marks inventory dirty. 331–358 registration deduplicates bundle+offset, retires pointer cache entry, inserts fresh snapshot and retains aliasing shared ownership. Texture epoch updates snapshot bytes and inventory revision independently (253–289). Bundle generation and snapshot generation are distinct; neither frame-local adapted index nor raw pointer alone is a persistent identity. Proposed first key: producer namespace + snapshot generation + representation revision; transformed payload additionally keys exact transform and coordinate convention. Zero generation falls back. Must verify all upstream retirement/mutation callers and bundle reload handling before treating this as exhaustive; bundle load itself does not visibly retire every pointer cache entry. Inventory ownership may outlive pointer cache retirement. GPU cache must own its payload and not retain unowned native pointers.

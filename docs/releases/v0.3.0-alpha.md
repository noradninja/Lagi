# Lagi v0.3.0-alpha — Authentic Boot to Native Ruins

This release marks the point where Lagi boots *Panzer Dragoon Saga* through Azel's native startup flow and reaches a playable first Ruins scene on PlayStation Vita without relying on the earlier direct-Ruins development bootstrap.

The game now enters through `azelInit()` / `resetEngine()`, follows the original task and module flow through the opening movies, title, New Game, D5 name entry, and pre-Ruins cinematic, then lets Azel load `TWN_RUIN.PRG` and create the native town task graph.

## Architecture

The release keeps the ownership model established during the 0.040 work:

```text
Azel decides.
Lagi services.
Neptune renders.
```

Azel remains responsible for startup flow, game modes, tasks, scripts, camera, collision, animation, visibility, object lifetime, VDP1 command generation, VDP2 state, and transitions.

Lagi supplies Vita input, disc/filesystem access, timing, audio, frame synchronization, memory/resource adaptation, and the presentation bridge.

Neptune translates the published Saturn-era rendering state to native SceGxm.

The normal release path does not depend on `init_town_bootstrap()`, `init_town_runtime()`, manual `overlayStart_TWN_RUIN()`, or static-room viewer registration.

## Rendering

The native Ruins path now presents:

- static world geometry from Azel's world-grid submissions;
- task-owned dynamic objects;
- Edge's animated hierarchy;
- live VDP1 materials decoded from Saturn VDP1 memory;
- live Azel directional/falloff lighting;
- original Edge mesh shadow and town UI primitives.

Static geometry/material caching is independent from live light state, allowing lighting to update without rebuilding the room.

The current Full/Lighting path still performs Saturn-style per-corner Gouraud evaluation on the CPU before SGX interpolation. GPU-side evaluation is a later renderer optimization and is not required for the 0.040 milestone.

## Controls

Current Vita mapping:

| Vita | Saturn |
|---|---|
| Square | A |
| Cross | B |
| Circle | C |
| Triangle | Y |
| L / R | L / R |
| Start | Start |
| Left analog | Analog X/Y |
| D-pad Up / Down | D-pad Up / Down |
| D-pad Left / Right | Neptune view cycle |
| Select | Performance OSD |
| Start + Select | Full debug/status screen |

A/C enter or select Lock-On targets, B cancels Lock-On and runs while moving, and the analog stick controls Edge through Azel's original walk-mode logic.

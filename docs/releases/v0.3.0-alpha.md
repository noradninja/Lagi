# Lagi 0.3.0 — Native Audio & Cinepak Presentation

Lagi 0.3.0 is a major runtime milestone for the native *Panzer Dragoon Saga* runtime on PlayStation Vita.

The release carries the authentic Azel boot path through the playable Ruins sequence and its final post-elevator cinematic, while bringing the original game's audio path substantially online through native Vita audio and hardware-validated SCSP DSP translation.

GitHub release tag: `v0.3.0alpha`

## Highlights

- Complete supported flow from first boot through the final cinematic after the Ruins area
- Consistent 30 FPS presentation in the supported 3D sequence, with sub-22 ms render work on the release route
- Native Vita BGM and sound-effect playback
- Runtime ARM translation of Sega Saturn SCSP DSP programs
- Hardware-validated DSP execution on real Vita hardware
- 84-step DSP program reduced from approximately 5.3 ms to 2.3 ms median
- Audio processing inside the tested Vita audio quantum budget
- Disc-entry audio nearly free of the earlier crackle
- Sega FILM / Cinepak playback with native SceAudio
- SGX-assisted Cinepak reconstruction at native file frame rates
- Cinepak reconstruction at source resolution followed by hardware-linear final presentation
- Native Azel title, name-entry, front-end, Ruins, and elevator flow
- Native VDP2 front-end presentation including the 720x408 high-resolution title mode
- Native Neptune/SceGxm rendering with MSAA disabled

## Runtime ownership

The release continues to follow the same architecture:

```text
Azel decides.
Lagi services.
Neptune renders.
```

Azel remains responsible for startup flow, game modes, tasks, scripts, camera, collision, animation, visibility, object lifetime, VDP1 command generation, VDP2 state, audio sequencing, movies, and transitions.

Lagi supplies Vita input, disc/filesystem access, timing, audio output, frame synchronization, SCSP DSP translation, memory/resource adaptation, and the presentation bridge.

Neptune translates the published Saturn-era presentation state to native SceGxm.

## Native audio

Runtime ARM translation is the default SCSP DSP backend for normal builds. No `ux0:data/lagi/dsp_backend.txt` file is required.

The file remains available for diagnostics and can explicitly select `predecoded`, `reference`, `auto`, `aot`, or `arm`.

Hardware validation of the 84-step DSP program measured a 2,268 us median and 2,392 us P95, compared with a corrected 5,264 us predecoded median. The corresponding whole audio quantum measured 5,297 us median against a 5,804 us budget, with zero short writes.

## Cinepak presentation

Cinepak data remains point-exact while the SGX reconstruction shader interprets the compact payload. The reconstructed source-resolution RGBA frame is then sampled through the normal hardware-linear texture path for final presentation.

This keeps the packed Cinepak decode exact while removing the nearest-neighbor scaling behavior of the earlier single-pass path.

## Known issues

- VDP2 bitplane support remains a work in progress. The D5 name-entry screen still has visible presentation errors, but the sequence is functional and continues once Azel advances it.
- Flight mode is not implemented yet. After the post-elevator FMV, Azel advances toward the next game mode and the current build fades to black. This is the end of the supported 0.3.0 slice.

## Game data

The release requires a user-supplied original *Panzer Dragoon Saga* Disc 1 image in matching BIN/CUE form:

```text
ux0:/data/Lagi/Disc 1/*.bin
ux0:/data/Lagi/Disc 1/*.cue
```

The BIN and CUE filenames must match.

Lagi does not include or distribute copyrighted *Panzer Dragoon Saga* game data.
